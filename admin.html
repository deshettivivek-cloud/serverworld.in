⚙️ Vercel Deployment & Live JSON Data Sync

How to manage exams and candidates on Vercel without a PHP server.

⚡ How Live Data Works on Vercel:
1. Any student accounts, exams, and courses you create in this Admin Console are saved immediately to your browser's local database so you can test them live.
2. To persist new candidates and tests across all devices globally on Vercel, simply click "Download Updated JSON" below and push them to your GitHub repository (https://github.com/deshettivivek-cloud/serverworld.in). Vercel will redeploy in 15 seconds!
